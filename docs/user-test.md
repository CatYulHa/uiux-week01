실제 참여자와 진행한 테스트를 적는 문서입니다. `[ ]`는 테스트를 마친 뒤 직접 채웁니다. 이름 대신 P01처럼 참여자 코드만 쓰고, 발화는 들은 말 그대로 적습니다.

- 진행 상태: 양식 준비 완료, 참여자 테스트 진행 전
- 진행 순서: 양식 A 준비 → 양식 B 읽기 → T1·T2 진행하며 양식 C → 과업마다 양식 D → 문제 하나 고치기 → 같은 과업 2차 진행 → 양식 E

## 양식 A · 테스트 계획서·과업지

- 서비스·주로 사용할 사람: UI/UX 기초를 예제로 배우는 학습 페이지 · UI/UX를 처음 배우는 학습자
- 확인할 질문: 새로고침 뒤 작성하던 내용이 돌아온 것을 알아차리고 다시 입력하지 않고 끝낼 수 있는가, 이전 내용을 지우고 처음부터 시작하는 방법을 찾을 수 있는가
- 테스트 버전·배포 주소: 1차 `e5e1160` · https://catyulha.github.io/uiux-week01/
- 참여자 코드·서비스나 코드를 본 경험: P01 · [ ]
- 실제 참여 인원·진행자·기록자: [ ]명 · 진행 하율 · 기록 [ ]
- 기기·브라우저·화면 너비: [ ]
- 과업별 제한 시간: 5분
- 도움을 줄 기준: 1분 넘게 멈추면 "지금 무엇을 찾고 있나요?"만 묻습니다. 참여자가 도움을 요청하거나 3분이 지나도 진행하지 못하면 위치를 알려 주고 '도움 제공'으로 적습니다.

### 과업 T1 · 대표 과업: 작성 중 새로고침 뒤 이어서 저장

- 참여자에게 읽을 문장: "오늘 배운 점을 학습 기록으로 남기던 중에 화면이 새로고침됐어요. 쓰던 내용으로 학습 기록을 마저 저장해 주세요."
- 시작 화면·입력값 (진행자가 준비)
  1. 새 탭에서 배포 주소를 열고 '저장한 기록'이 0개인지 확인합니다. 기록이 있으면 '자세히 보기'에서 삭제합니다.
  2. 학습 기록 폼에 아래 값을 입력합니다.
     - 실습한 예제: `코드 예제 바꿔보기`
     - 오늘 배운 점: `공통 버튼은 .button 기본 클래스에 변형 클래스를 더해 만든다.`
     - `헷갈린 부분이 있어요` 체크
     - 헷갈린 부분: `data-action과 data-id를 언제 나눠 쓰는지 헷갈린다.`
  3. 저장하지 않고 새로고침(F5)합니다. 화면을 맨 위로 올린 뒤 참여자에게 넘깁니다.
- 진행자용 완료 기준: '저장한 기록'에 `코드 예제 바꿔보기` 카드가 `복습 필요` 라벨과 함께 보입니다. 같은 내용을 다시 입력했는지는 따로 적습니다.

### 과업 T2 · 다른 경로: 이전 내용을 지우고 처음부터

- 참여자에게 읽을 문장: "학습 계획을 세우던 중에 화면이 새로고침됐어요. 이전에 쓰던 계획은 지우고, 'UI와 UX의 차이 설명하기'라는 새 목표로 계획을 처음부터 세워 확정해 주세요."
- 시작 화면·입력값 (진행자가 준비, T1과 같은 탭)
  1. '학습 계획 세우기' → 목표 `모달과 아코디언 차이 이해하기` → '학습 목표 정하기' → '다음 · 예제 고르기'
  2. 예제 `UI와 UX 비교하기`, 학습 시간 `30분` → '다음 · 계획 확인'
  3. 확정하지 않고 새로고침(F5)합니다. 화면을 맨 위로 올린 뒤 참여자에게 넘깁니다.
- 진행자용 완료 기준: 계획 완료 화면의 학습 목표가 `UI와 UX의 차이 설명하기`이고 이전 목표가 남지 않습니다.
