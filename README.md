# UI/UX 프로그래밍 · 1주차

- 주제: UI/UX 프로그래밍의 이해와 웹 인터페이스의 기본 구조

## 구성

- `index.html`: UI와 UX 설명, 좋은 경험의 5원칙, 웹 기술 소개, 인터랙션 실습
- `style.css`: 녹색 계열 디자인, 모바일 반응형 레이아웃, 키보드 포커스 표시
- `script.js`: 기술 소개 탭 전환, 키보드 탐색, 클릭 카운터와 초기화
