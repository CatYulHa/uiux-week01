# UI/UX 프로그래밍 · 1주차

- 이름: 하율
- 학번: 12406050
- 주제: UI/UX 프로그래밍의 이해와 웹 인터페이스의 기본 구조

## 구성

- `index.html`: UI와 UX 설명, 좋은 경험의 5원칙, 웹 기술 소개, 인터랙션 실습
- `style.css`: 녹색 계열 디자인, 모바일 반응형 레이아웃, 키보드 포커스 표시
- `script.js`: 기술 소개 탭 전환, 키보드 탐색, 클릭 카운터와 초기화

## 실행

`index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행합니다. 빌드 과정은 없습니다. Google Fonts를 불러오지 못해도 기본 글꼴로 표시됩니다.

## GitHub Pages 배포

1. GitHub에 `uiux-week01` 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `script.js`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.
5. 배포가 완료되면 Pages에 표시되는 사이트 주소를 열어 확인합니다.
