# 한걸음 UI/UX · 2주차

웹을 처음 배우는 대학생이 개념과 코드, 작은 실습으로 좋은 사용자 경험을 배워가는 학습 서비스입니다.

- 수업: UI/UX 프로그래밍
- 2주차 주제: HTML로 사용자 경험의 구조 만들기

## 제출 주소

- GitHub Repository URL: https://github.com/CatYulHa/uiux-week01
- Published Website URL: https://catyulha.github.io/uiux-week01/
- 연결된 학습실: https://catyulha.github.io/uiux-week01/learn.html

1주차와 같은 저장소와 GitHub Pages 주소를 사용합니다.

## UX 기획

- 사용자: UI와 UX, 웹의 기본 구조를 처음 배우는 대학생.
- 목적: 서비스의 학습 내용과 이용 방법을 이해하고 첫 웹 학습을 시작한다.
- 핵심 행동: 페이지 안에서 필요한 정보를 찾고, 오늘의 학습 목표를 입력한 뒤 학습실을 이용한다.
- 정보 순서: 서비스 이름과 한 줄 소개 → 서비스 소개 → 주요 기능 3개 → 이용 방법 3단계 → 학습 목표 입력 → 하단 정보.

같은 기획 내용을 `index.html`의 `<body>` 시작 부분에 HTML 주석으로 기록했습니다.

## 2주차 요구사항 반영

| 요구사항 | 구현 위치와 내용 |
| --- | --- |
| 사용자·목적·핵심 행동·정보 순서 주석 | `body` 시작 부분의 UX 기획 주석 |
| 서비스 이름과 한 줄 소개 | `header`의 `h1`과 소개 문단, 서비스에 맞춘 `title` |
| 서비스 소개 | `section#about`, `h2` → `h3` → `p` |
| 주요 기능 3개 | `section#features`의 `ul`과 세 개의 `li`, 각 항목에 `h3`와 `p` |
| 이용 방법 3단계 | `section#steps`의 `ol`: 목표 정하기 → 개념과 예제 살펴보기 → 직접 누르고 확인하기 |
| 이미지 1장과 대체 텍스트 | `assets/images/service.png`, 실제 학습실 화면을 설명하는 `alt`, `figure`와 `figcaption` |
| 최소 입력 영역 | `section#start`의 `form`, 연결된 `label`과 `input`, `type="submit"` 버튼 |
| 페이지 내부 이동 | `nav`의 네 링크와 동일한 section id, 본문 바로가기와 맨 위로 링크 |

## 구현하면서 바꾼 구조와 이유

1. **학습 내용 중심에서 서비스 소개 중심으로 변경:** 첫 화면에서 서비스 대상과 할 수 있는 일을 먼저 이해하도록 구성했습니다. 1주차의 개념 설명·코드 탭·인터랙션 실습은 `learn.html`로 옮기고 주요 기능에서 직접 연결했습니다.
2. **정보에 맞는 시맨틱 영역 사용:** 서비스 이름과 소개·메뉴는 `header`, 주요 내용은 `main`의 네 `section`, 작성자와 하단 링크는 `footer`에 배치했습니다. 페이지 대표 제목은 `h1` 하나, 영역 제목은 `h2`, 하위 항목은 `h3`로 구분했습니다.
3. **기능과 이용 순서 구분:** 기능은 순서 없이 골라볼 수 있어 `ul`, 이용 방법은 학습 행동 순서가 있어 `ol`을 사용했습니다.
4. **입력 목적을 서비스에 맞게 변경:** 교안 예제의 이메일 알림 신청 대신 학습 목표 한 줄을 입력하도록 했습니다. `label for="learning-goal"`과 `input id="learning-goal"`을 연결하고, 버튼 문구를 ‘학습 목표 정하기’로 정했습니다.
5. **메뉴와 도착 영역 일치:** 서비스 소개·주요 기능·이용 방법·학습 목표라는 메뉴 이름을 각 영역 제목과 맞추고 `href`와 `id`를 연결했습니다.
6. **실제 서비스 이미지 포함:** 1주차 학습실의 UI·UX 비교 화면을 직접 캡처해 저장소에 포함했습니다. 이미지가 로드되지 않아도 내용을 이해하도록 대체 텍스트를 작성했습니다.
7. **기존 표현과 상호작용 유지:** 1주차의 녹색 계열 디자인과 반응형 레이아웃을 이어 사용했습니다. 학습실 하단에는 서비스 소개로 돌아가는 링크를 추가했습니다.

## 파일 구성

```text
uiux-week01/
├── index.html                # 2주차 서비스 소개와 UX 기획 주석
├── learn.html                # 1주차 내용을 연결한 학습실
├── style.css                 # 공통 디자인과 모바일 레이아웃
├── script.js                 # 학습 목표 입력 결과 표시
├── learning.js               # 기존 기술 탭과 클릭·초기화
├── assets/images/service.png # 직접 캡처한 서비스 화면
└── README.md                 # 서비스 소개, 변경 이유, 제출 주소
```

## 실행과 입력 동작

`index.html`을 브라우저에서 열거나 VS Code Live Server로 실행합니다. 빌드나 패키지 설치는 필요하지 않습니다. Google Fonts를 사용할 수 없으면 기본 글꼴로 표시합니다.

학습 목표는 필수이며 최대 80자입니다. 제출하면 현재 화면에 목표와 학습실 이동 링크를 표시합니다. 서버 전송이나 영구 저장은 하지 않으며 새로고침하면 지워집니다. JavaScript가 꺼져 있으면 목표 확인 버튼은 비활성화되고 안내 문구와 학습실 링크를 제공합니다.

## 브라우저 확인 결과

- 320px, 390px, 768px, 1440px 너비에서 가로 넘침 없이 표시됨.
- 주요 기능 3개, 이용 방법 3단계, `h1` 하나, 연결된 입력 레이블 확인.
- 네 개의 내부 메뉴와 본문 바로가기·맨 위로 링크의 대상 확인.
- 이미지 로딩과 실제 크기, 대체 텍스트 확인.
- 빈 목표와 공백만 있는 목표의 제출 방지, 정상 목표 제출과 Enter 키 동작 확인.
- 입력 내용은 텍스트로 표시되며 새로고침 후 초기화됨.
- 기존 학습실의 기술 탭, 방향키 탐색, 클릭 카운터, 초기화 확인.
- JavaScript가 꺼져 있어도 소개·목록·이동 링크가 표시됨.

## 배포

GitHub Pages가 `main` 브랜치의 `/ (root)`를 배포합니다. 변경 내용을 작업 단위로 커밋한 뒤 `main`에 push하면 같은 공개 주소가 갱신됩니다.
